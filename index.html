FAQ

Questions worth asking.

Where do my API key and chats live?

In this browser's localStorage, under keys prefixed with cline.. Nothing is uploaded. Clearing site data or using a different browser starts you fresh.

Is the sign-up a real authentication system?

No — and that is deliberate. Accounts are created and verified locally so the app can keep separate workspaces per person on a shared machine. There is no backend, so treat it as a profile switcher rather than a security boundary.

What does it cost?

The app is free. You pay each provider directly for the tokens you use, at their own rates.

Can I use a model that isn't in the list?

Yes. Settings has an "Other model ID" field that accepts any identifier listed on openrouter.ai/models.

Can I host this for my team?

You can, but put a small proxy in front of the provider that holds the key server-side, then point CLINE AI at it with the custom base URL. A browser-held key is visible to anyone using that browser.
